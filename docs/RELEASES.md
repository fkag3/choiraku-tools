# Release Guide

## 1. 公開前の確認

- [ ] 作業ブランチの変更をPull Requestで確認した
- [ ] Pull Requestを `main` にマージした
- [ ] 変更内容に問題がないことを確認した
- [ ] 必要に応じてREADME.mdを更新した
- [ ] 必要に応じてCHANGELOG.mdを更新した
- [ ] APIキーやパスワードなどの秘密情報を含めていない

## 2. テスト

- [ ] 追加・修正した機能が正常に動作する
- [ ] 空欄や不正な入力でも問題がない
- [ ] PCで表示を確認した
- [ ] スマートフォンで表示を確認した
- [ ] ブラウザのコンソールにエラーがない
- [ ] 既存の機能が正常に動作する

## 3. 公開作業

1. `main` ブランチの最新状態を確認する
2. 公開先のデプロイ方法を確認する
3. 必要な場合は手動でデプロイを実行する
4. 自動デプロイの場合は、処理の成功を確認する

## 4. 公開後の確認

- [ ] 公開サイトにアクセスできる
- [ ] 追加・修正した機能が動作する
- [ ] ページやリンクが正しく表示される
- [ ] PCとスマートフォンで表示を確認した

## 5. 問題が発生した場合

1. エラー内容と発生した操作を記録する
2. 影響する機能やページを確認する
3. 必要に応じて公開先の前の正常なバージョンに戻す
4. 修正ブランチで問題を修正する
5. Pull Requestで確認してから再公開する
